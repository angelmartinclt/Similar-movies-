<h1><em>Similar Movies Application</em></h1>

Here is the completed Similar Movies Application, through the hosted link users can type in a movie they enjoy and get hand crafted reccomendations for movies alike using the TMDB API!

This application was built utilizing Node.js, Handlebars and Express.

<h2>Features</h2>
<ul>
<li>Users can search for a movie using the search bar</li>
<li>Users can find similar movies based off of the one they selected</li>
<li>Users have a responsive application that utilized design principles</li>
</ul>
